# SharkHabits V7 — Style E / Semi-réaliste lumineux

V7 remplace les requins et décorations vectoriels/cartoon de V6 par une bibliothèque d'assets raster illustrés, dérivée de la direction artistique Style E choisie.

## V7
- 25 visuels de requins distincts en PNG.
- 10 visuels de décorations en PNG.
- Fonds d'aquarium Jour / Soir / Nuit en WebP.
- Le fond change automatiquement selon l'heure.
- Sharkdex : tous les requins restent visibles, cadenas superposé s'ils sont verrouillés.
- Aquarium plein écran et personnalisable conservé.
- Suivi, statistiques, boutique et collection conservés.
- Migration automatique des données V6 au premier lancement.
- Aucun boss, aucune exploration, aucun objectif précréé.

## GitHub Pages
Tous les fichiers sont à déposer directement à la racine de `main`. Aucun dossier `assets` ou `images`.

Cache : `sharkhabits-v7.0.0-style-e`.
