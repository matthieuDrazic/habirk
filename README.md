# SharkHabits V13.0 — Stable Interactions

Correctif structurel de la V12/V12.1 :
- restauration des fonctions quotidiennes manquantes qui bloquaient `render()` au démarrage ;
- suppression du listener global de clic V12.1 ;
- boutons + et − liés uniquement à leurs propres cartes ;
- navigation basse et icônes de l'application de nouveau indépendantes ;
- navigation lundi→dimanche fonctionnelle ;
- + sur une habitude ajoute 1, − retire 1 sur le jour sélectionné ;
- + sur un cumul ajoute une quantité au total existant ;
- − retire une quantité saisie, sans retirer plus que ce qui a été saisi ce jour-là ;
- conservation des poissons, tortues, boutique en dents et océan sans flou ;
- migration V12.1 → V13 ;
- version visible V13.0 ;
- cache `sharkhabits-v13.0.0-stable-interactions`.
