# SharkHabits V16.0 — Tracking Identity

- 4 identités de suivi : Habitude, Cumul, Mesure, Échéance.
- Habitude : mini-semaine visuelle.
- Cumul : jauge + réel / cible.
- Mesure : sparkline et direction Diminuer / Augmenter / Maintenir.
- Échéance : anneau + jours restants.
- Fiche détaillée : courbe réelle + trajectoire théorique jusqu'à l'échéance.
- Poids 70 → 60 : trajectoire théorique descendante calculée selon le temps.
- Boutons + ET − restaurés sur les cartes.
- − sur cumul/habitude corrige le jour sélectionné sans passer sous zéro.
- − sur mesure supprime la mesure du jour.
- Historique : suppression d'une entrée.
- Architecture V15 propre conservée; aucune réintroduction de code V14.
