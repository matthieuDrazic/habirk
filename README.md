# SharkHabits V5

V5 recentrée sur les visuels et l’aquarium.

- 5 onglets : Océan, Suivi, Stats, Requins, Boutique.
- Exploration supprimée.
- Objectifs, habitudes et planning réunis dans **Suivi** (Aujourd’hui / Semaine / Tous).
- 25 requins avec **25 fichiers SVG distincts**, tous visibles même verrouillés avec cadenas.
- Aquarium plein écran, décoration depuis cette vue, inventaire, gestion des requins présents.
- Kit de décoration offert au départ.
- Boutique requins + décorations.
- Données V4 (objectifs, activités, XP, dents) migrées automatiquement au premier lancement de V5 si elles existent.
- Aucun objectif précréé, aucun boss, aucune exploration.

## GitHub Pages
Tous les fichiers sont à mettre **directement à la racine de `main`**. Les SVG des requins et décorations sont eux aussi à la racine. Aucun dossier `assets/` ou `images/`.

Après commit : Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Cache : `sharkhabits-v5.0.0`.
